# 🌤️ 当地天气 (Local Weather)

一个纯净、轻量、高颜值的实时天气预报 Web 应用。支持高精度自动定位、全球城市搜索、24小时逐时预报、未来7天预报、8项核心气象指标、动态天气粒子动画与智能生活出行建议。

- 🌐 **线上部署**：[https://weather.505250.xyz](https://weather.505250.xyz) (由 Cloudflare Edge 强力驱动)
- 📦 **GitHub 仓库**：[huangti/local-weather](https://github.com/huangti/local-weather)
- ⚡ **无依赖运行**：纯原生 HTML5 + CSS3 + Vanilla ES6+，零外部庞大框架，即开即用

---

## ✨ 功能特点

1. **自动定位与城市切换**：
   - 自动获取当前地理位置气象信息（优先浏览器高精度 GPS 定位，受限时智能自动切换 IP 定位兜底）。
   - 全球任意城市或区县中英文搜索与即时联想输入。
   - 快捷热门城市（北京、上海、广州、深圳、杭州、成都等）一键直达。
   - 城市收藏夹功能（点击城市旁边的 ⭐ 即可一键收藏与快速切换）。

2. **核心实时气象展示**：
   - 当前气温、天气状况（晴、多云、阴、雨、雪、雷暴等）。
   - 今日最高/最低气温、体感温度。
   - 智能今日天气综合概括与出行建议。

3. **24 小时逐时预报**：
   - 未来 24 小时温度变化、天气图标及降水概率。
   - 支持平滑横向拖拽与滑动。

4. **未来 7 天精细预报**：
   - 每日天气趋势、降水概率。
   - 极具视觉感的高低温温差跨度图条。

5. **8 项关键生活与气象指标**：
   - 🌡️ **体感温度**（结合风速与湿度的体感评判）
   - 💧 **相对湿度**（含干燥/适宜/潮湿健康提示）
   - 🍃 **风向与风速**（蒲福风力等级与风向描述）
   - ☀️ **紫外线指数**（UV 分级及防晒建议）
   - 🍃 **空气质量 AQI**（含 PM2.5 / PM10 浓度及优良中差评级）
   - 🌧️ **今日降水量**（实时降水量 mm 与降水概率 %）
   - ⏱️ **大气压强**（hPa 与气压稳定性评估）
   - 🌅 **日出与日落**（今日日出/日落时间）

6. **生活指数与出行建议**：
   - 穿衣指南、户外运动建议、感冒预防指数、衣物晾晒指数、洗车建议、舒适度评估。

7. **动态天气氛围特效**：
   - 根据当前天气状况与昼夜状态（白天/夜晚）自动切换主题背景。
   - Canvas 物理粒子模拟（雨滴淅沥、雪花飘扬、夜幕繁星、晴日柔光）。
   - 支持 °C / °F 单位一键切换。

## 🚀 本地运行方式

如果你需要在本地离线或测试运行，可以通过以下任意方式打开：

### 方式一：双击一键启动（推荐）
在桌面的 `当地天气` 文件夹中，**双击运行 `启动天气.command`**（或 `start.command`）：
- 会自动启动本地轻量 HTTP 服务并打开 `http://localhost:8088`。
- 本地服务启动后，浏览器的地理定位安全限制会自动放行，可精准获取当前位置。
- 如需关闭，在弹出的终端窗口按 `Ctrl + C` 即可。

### 方式二：直接在浏览器打开
双击直接用浏览器（如 Safari、Chrome、Edge）打开 `index.html` 即可使用。

## ☁️ Cloudflare 部署架构

本项目通过 Cloudflare Worker (`local-weather`) 直接全球边缘加速分发：
- 静态资产与路由处理由 Edge Worker 直接响应，首屏加载毫秒级直达。
- 自定义域名绑定至 `weather.505250.xyz`，自动配置 Cloudflare SSL/TLS 证书。
- 气象数据均基于 Open-Meteo 全球开放气象观测网络与 OpenStreetMap，免个人 API 密钥，免登录，零追踪。
